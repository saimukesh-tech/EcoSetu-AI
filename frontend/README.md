# EcoSetu AI — Frontend

React + TypeScript + Vite + Tailwind web app for EcoSetu AI.

See the [top-level README](../README.md) for full setup instructions, environment variables, and project structure.

## Quick start

```bash
npm install
npm run dev       # http://localhost:5173
```

```bash
npm run build     # production build, output in dist/
npm run preview   # preview the production build locally
```
